# ⛽ GasMaps: Smart Route & Gas Optimizer

A high-performance React application designed to simplify travel. By integrating **Mapbox GL JS**, GasMaps provides real-time navigation, identifies nearby fuel stations, and intelligently highlights the most cost-effective options along your route.

---

## ✨ Features

* 📍 **Live User Location:** Instantly centers on your position using the Browser Geolocation API.
* 🗺 **Interactive Map:** High-performance vector maps powered by Mapbox GL.
* 🛣 **Turn-by-turn Routing:** Visualized paths with real-time distance and duration estimates.
* ⛽ **Smart Gas Markers:** Nearby stations with custom markers (currently using mock data).
* 💲 **Best Price Logic:** Automatically identifies and highlights the cheapest gas station in the vicinity.
* 🔍 **Geocoding Search:** Search for any destination worldwide via the Mapbox Geocoding API.
* 📱 **Responsive UI:** Clean, modern dashboard built with Tailwind CSS for mobile and desktop.
